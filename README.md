# Nayae Consulting & Energy Projects Ltd — Website starter

This ZIP contains a multi-page responsive corporate website built with HTML, CSS, and JavaScript.

## Pages included
- `index.html` — Home
- `about.html` — About Us
- `ai-solutions.html` — AI-Powered Security Solutions
- `pipeline-security.html` — Pipeline Security & Critical Infrastructure Protection, including the workflow diagram
- `industries.html` — all eight requested industry areas, excluding Agriculture, Truck Yards, Shopping Malls, and Self-Storage
- `services.html` — four major service categories
- `contact.html` — contact form layout, industry selection, and service inquiry options
- `privacy.html` — privacy policy starter
- `css/style.css` — styling, responsive layouts, animations
- `js/main.js` — mobile navigation, dropdowns, form demo status, current year
- `WEBSITE_REQUIREMENTS_VERBATIM.txt` — the full requirements text supplied in the prompt, preserved verbatim

## Open the website
1. Extract the ZIP file.
2. Open `index.html` in a browser.
3. For a more realistic local development setup, open the folder in Visual Studio Code and use a local server extension.

## Important before launch
This is a front-end starter, not a fully deployed production website. Please complete these items before presenting it as fully operational:
- Replace the business email, phone number, and company location placeholders with confirmed details.
- Connect the contact form to the designated company email or an approved form backend. The current form intentionally displays a notice and does not send email.
- Review and approve the privacy policy and cookie/analytics requirements.
- Add the company's official logo and brand assets if available.
- Verify that the selected remote images are appropriately licensed for commercial use, or replace them with approved licensed imagery. The current imagery uses Unsplash image URLs and requires license/asset verification.
- Configure domain, hosting, HTTPS/SSL, security headers, spam protection, analytics, sitemap, and search console as appropriate.
- Test all pages, links, mobile layouts, form delivery, accessibility, and performance before launch.
- Set up a content management system if non-technical staff need to edit pages and images. This static HTML version does not include a CMS.

## No invented credentials
The copy avoids claiming unconfirmed certifications, clients, partnerships, years of experience, proven deployments, testimonials, or performance statistics. Where the original brief asks for information that was not provided, the site uses clearly marked placeholders or careful proposed-solution language.
